JavaWeb 课程知识分章总结

跟着 B 站黑马程序员的 JavaWeb 全套课程学习（课程地址，共 200 集，覆盖 SpringBoot + MyBatis + SpringMVC 全流程企业开发）。这篇文章把课程知识按章节整理：第一节是学习路线，后面每一节对应课程的一个知识模块。每章末尾附对应的视频分 P。

第一节：学习路线

  • 前端篇（P2–49）：HTML/CSS、JavaScript、Vue 快速入门、Axios、前端工程化与 Element 组件库
  • 后端基础篇（P50–134）：Maven、SpringBoot Web 入门、HTTP 协议、请求响应、分层解耦（IOC/DI）、MySQL、MyBatis
  • 后端实战篇（P135–199）：部门/员工管理案例、文件上传、登录认证（JWT/Filter/Interceptor）、事务与 AOP、SpringBoot 原理、Maven 高级

我的进度：P1–P74 已完成，当前在 P75（分层解耦-三层架构）。

第二节：前端开发基础

2.1 HTML 与 CSS

  • HTML 骨架：<html> → <head>（标题/字符集）+ <body>；核心是标签 + 属性。
  • 常用标签：标题 h1-h6、段落/换行、图片 <img src width>、超链接 <a href target="_blank">、音视频、<div>/<span> 布局盒子。
  • 表格：<table> → <tr> 行 → <th>/<td> 单元格；colspan/rowspan 跨列跨行。
  • 表单：<form action method> 内放 <input type=text/password/radio/checkbox/file/date/hidden/submit>、<select>、<textarea>；提交服务器的要素：name 属性 + 表单项 + 提交按钮。
  • CSS：引入方式（行内/内嵌/外联）；选择器（元素、类 .、id #、属性）；盒子模型（content + padding + border + margin）；布局用 flex 弹性盒子。

视频：P3–P14

2.2 JavaScript

  • 基础语法：var/let/const、数据类型（number/string/boolean/null/undefined）、typeof、== 与 ===、模板字符串。
  • 函数与对象：function 声明 / 匿名 / 箭头函数 =>；JSON：JSON.stringify() 序列化、JSON.parse() 解析（属性名必须双引号）。
  • BOM：window（alert/confirm/setInterval/setTimeout）、location（href 跳转）、DOM：document.getElementById/querySelector 获取元素后改 innerHTML/style。
  • 事件绑定：元素.onclick = function(){} 或 addEventListener；常见事件 click/dblclick/mouseover/keyup/submit/change/focus/blur。

视频：P15–P28

2.3 Vue 与 Axios

  • Vue 快速入门：引入 vue.js → new Vue({el, data, methods})；常用指令：v-bind（:）绑定属性、v-model 双向绑定表单、v-on（@）绑定事件、v-if/v-show 条件、v-for 列表渲染；生命周期：created（数据可用）/mounted（DOM 可用）最常用。
  • Ajax：异步不刷新地与服务端交换数据；Axios：axios.get(url).then(res => ...) / axios.post(url, data)。
  • 前端工程化：Node.js + Vue CLI 创建工程化项目，npm run serve 启动；目录：src/main.js/App.vue/views/components。
  • Element 组件库：按文档复制组件（Table 表格、Pagination 分页、Dialog 对话框、Form 表单），数据驱动视图；vue-router 路由跳页面，npm run build 打包部署。

视频：P29–P49

第三节：Maven 与 Web 入门

3.1 Maven

  • 是什么：项目构建与依赖管理工具；核心概念坐标（groupId/artifactId/version）唯一定位一个 jar。
  • 依赖配置：<dependency> 引坐标；依赖传递：A 依赖 B、B 依赖 C，则 A 可用 C；exclusions 排除传递依赖。
  • 依赖范围：compile（默认，全程）/ test（仅测试）/ provided（编译期，运行由容器提供）。
  • 生命周期：compile → test → package → install（进本地仓库）；常用 IDEA 图形化按钮执行。

视频：P50–P57

3.2 SpringBoot Web 快速入门

  • 创建 SpringBoot 工程（spring-boot-starter-web 起步依赖），写一个请求处理类即可跑起 Web 服务，内嵌 Tomcat，无需手动部署 war。
  • 三个基础注解起步：@SpringBootApplication（启动类）、@RestController、@RequestMapping("/xxx")。

视频：P58–P59

3.3 HTTP 协议

  • 请求协议：请求行（方式 + URL + 协议版本）→ 请求头（Host/User-Agent/Content-Type）→ 请求体（GET 一般无，POST 放数据）。
  • 请求方式：GET（查询，参数拼 URL）、POST（提交数据放请求体）。
  • 响应协议：状态行 + 响应头 + 响应体；状态码：200 成功、302 重定向、304 走缓存、404 资源不存在、405 方式不匹配、500 服务端异常。

视频：P60–P63

3.4 Tomcat

  • 开源 Web 服务器，负责监听端口、接收请求、调用我们的程序、返回响应；SpringBoot 内嵌 Tomcat（spring-boot-starter-web 传递引入），默认端口 8080，可用 server.port 修改。

视频：P64–P66

第四节：请求响应与分层解耦

4.1 请求参数接收

参数类型 写法 要点
简单参数 @RequestParam 名称不一致时 @RequestParam("name")；required=false 可选
实体参数 POJO 直接声明 属性名与参数名一致自动封装，可嵌套
数组集合 List<String> 需加 @RequestParam 才封装为集合
日期参数 @DateTimeFormat(pattern="yyyy-MM-dd HH:mm:ss")
JSON 参数 @RequestBody POJO POST + application/json
路径参数 @PathVariable RESTful 风格 /user/{id}

调试工具 Postman（Apifox 同理）。

视频：P67–P73

4.2 响应与统一响应结果

  • @ResponseBody：把方法返回值转 JSON 写回响应体；类上标 @RestController = @Controller + @ResponseBody。
  • 统一响应结果：所有接口返回一个 Result 类（Integer code; String msg; Object data;）+ 静态工厂 Result.success(data) / Result.error(msg)，前后端约定统一格式。

视频：P73–P74

4.3 分层解耦——三层架构（当前所在 P75）

  • 三层架构：按职责把后端拆成三层，单一职责、便于维护复用：
层 命名习惯 职责
表现层 / Web 层 XxxController 接收请求、返回响应（参数校验、调业务）
业务层 XxxService 具体业务逻辑（如批量删除要开事务）
数据访问层 / 持久层 XxxMapper / XxxDao 操作数据库（CRUD）
  • 依赖方向：Controller → Service → Mapper，逐层调用；Controller 不直接碰数据库。
  • 耦合问题：层与层之间直接 new Service实现类()，一旦实现类换名/换实现，调用方全要改——内聚与解耦要同时追求：类内部关系紧密（高内聚），类之间依赖越弱越好（低耦合）。

视频：P75

4.4 分层解耦——IOC 与 DI

  • 解耦思路：Service 只声明接口，Controller 面向接口编程；对象的创建权交给第三方（Spring 容器），用到时找容器要——这就是控制反转 IOC（Inversion Of Control）。
  • DI 依赖注入（Dependency Injection）：容器在创建 bean 时自动给成员变量赋值，是 IOC 的实现手段。
  • 声明 bean 的注解：@Component 通用；语义化衍生 @Service（业务层）、@Repository（持久层）、@Controller/@RestController（表现层）；默认单例，bean 名为类名首字母小写。
  • 注入注解：@Autowired 默认按类型装配，同类型多个时再按名称；@Primary 优先、@Qualifier("bean名") 指定、JDK 的 @Resource 按名称。
  • 注意：@ComponentScan 默认只扫描启动类所在包及其子包，所以包结构必须规范；第三方 jar 里的类没法加注解，用 @Configuration + @Bean（方法返回值进容器，参数自动注入），或 @Import 导入。

视频：P76–P79

第五节：MySQL 与 MyBatis

本篇只列课程主线，SQL 语句与原理细节见另一篇 MySQL 课程知识分章总结。

5.1 MySQL 基础（DDL / DML / DQL）

  • 数据模型：服务器 → 多数据库 → 多表；关系型数据库用二维表存数据。
  • DDL：库表增删改查；数据类型：INT/BIGINT、DECIMAL（金额）、VARCHAR、DATE/DATETIME。
  • DML：INSERT / UPDATE / DELETE（改删必须带 WHERE）。
  • DQL：SELECT ... WHERE ... GROUP BY ... HAVING ... ORDER BY ... LIMIT；聚合函数、分组统计、分页公式 LIMIT (页号-1)*页大小, 页大小。

视频：P80–P98

5.2 多表设计与多表查询

  • 表关系：一对多（多方加外键）、一对一（拆表 + UNIQUE 外键）、多对多（中间表两外键）；物理外键影响性能，互联网项目一般逻辑外键。
  • 查询：内连接 A JOIN B ON ...、外连接 LEFT JOIN 保留左表全部；子查询（标量子查询当值用、列子查询配 IN、行/表子查询）。

视频：P99–P110

5.3 事务与索引

  • 事务：START TRANSACTION ... COMMIT/ROLLBACK；ACID 四大特性（原子/一致/隔离/持久）。
  • 索引：帮 MySQL 高效查数据的有序结构，InnoDB 用 B+ 树（叶子存数据且双向链表，范围查询友好）；CREATE INDEX idx_xxx ON 表(列)。

视频：P111–P115

5.4 MyBatis

  • 是什么：优秀的持久层框架，简化 JDBC（自动注册驱动/建连接/释放资源，参数自动设置，结果集自动封装）；底层就是 JDBC + 反射 + 动态代理。
  • 数据库连接池：复用连接（Druid/HikariCP，SpringBoot 默认 Hikari）；Lombok：@Data/@Getter 等注解生成代码。
  • 基础 CRUD（注解版）：@Select/@Insert/@Update/@Delete 写 SQL；参数用 #{}（预编译，防 SQL 注入，底层 PreparedStatement），${} 是拼接（仅表名/排序字段等安全场景用）。
  • 主键返回：@Options(useGeneratedKeys = true, keyProperty = "id")，新增后回填自增 id。
  • XML 映射文件：复杂 SQL 写 XxxMapper.xml（namespace 对应接口全类名，id 对应方法名）。
  • 动态 SQL：<if test> 条件拼接 + <where> 去多余 AND；<foreach> 遍历集合（批量删除/插入）；<sql id> + <include refid> 抽公共片段。

视频：P116–P134

第六节：项目案例——部门与员工管理

6.1 案例准备与部门管理

  • 流程规范：看页面原型 → 阅读接口文档（Apifox）→ 设计表结构 → 按接口开发 → 前后端联调。
  • 部门管理三接口：查询列表（GET /depts）、删除（DELETE /depts?id=1）、新增（POST /depts + JSON body）；统一走三层架构 + Result 统一响应；日志用 @Slf4j 的 log.info()。

视频：P135–P139

6.2 员工管理：分页与条件查询

  • 分页插件 PageHelper：PageHelper.startPage(page, pageSize) 紧跟的查询自动分页，返回 Page<E>（含 total 记录数与 rows 当前页数据）。
  • 条件查询：姓名模糊 like concat('%',#{name},'%') + 性别 + 入职日期范围，全部接进动态 SQL。
  • 批量删除：路径参数 /ids/1,2,3 用 @PathVariable List<Integer> ids，SQL 用 foreach。

视频：P140–P144

6.3 新增/修改员工与文件上传

  • 新增员工：JSON 接收 + 补默认字段（UUID 工号、默认密码）。
  • 文件上传本质：前端 enctype="multipart/form-data" + POST；后端 MultipartFile 参数，transferTo() 存本地（配置上传大小限制）；本地存储的缺陷（磁盘占满、不共享）→ 阿里云 OSS：SDK ossClient.putObject(bucket, objectName, inputStream)。
  • 修改员工：按 id 查询回显 + 更新接口。

视频：P145–P152

6.4 配置文件

  • yml 语法：key: value 层级缩进；多数据源场景下可读性远好于 properties。
  • @Value 与 @ConfigurationProperties：批量把配置前缀映射成实体类字段（@ConfigurationProperties(prefix = "aliyun.oss")），再交容器管理，避免硬编码。

视频：P153–P155

第七节：登录认证（会话 / JWT / 过滤器 / 拦截器）

7.1 会话技术与 JWT

  • 登录校验：登录后每次请求都要识别”你是谁、登录没过期”——HTTP 无状态，需要会话跟踪。
  • 方案对比：
方案 存储位置 集群环境 跨域 移动端
Cookie 浏览器 ✓ 不友好 不友好
Session 服务器（SessionId 放 Cookie） 需共享（复制/Redis） 困难 不友好
JWT 客户端保存令牌 天然支持 支持 支持
  • JWT 组成：头.载荷.签名 三段；头/载荷只是 Base64 编码（不加密，别放敏感信息），签名用密钥防篡改。
  • 生成与校验（io.jsonwebtoken）：

视频：P156–P163

7.2 Filter 过滤器

  • @WebFilter(urlPatterns = "/*") + 实现 Filter：doFilter 里 chain.doFilter(req, resp) 放行；注册方式：@ServletComponentScan 或 FilterRegistrationBean（可设优先级）。
  • 登录校验过滤器：获取 JWT → 校验失败返回 401 的 JSON；放行登录接口；ThreadLocal 存当前登录人，业务层随时取（同一线程内共享，用完 remove）。

视频：P164–P168

7.3 Interceptor 拦截器与异常处理

  • 实现 HandlerInterceptor：preHandle（目标方法前，false 则拦截）/ postHandle / afterCompletion；WebMvcConfigurer.addInterceptors 注册 + excludePathPatterns 放行登录。
  • Filter 与 Interceptor 区别：拦截范围（所有资源 vs 仅 Spring 环境资源）、时机（更早 vs 前置处理附近）、是否容器 bean。
  • 全局异常处理：@RestControllerAdvice + @ExceptionHandler(Exception.class)，捕获后统一返回 Result.error(...)，业务代码不再到处 try-catch。

视频：P169–P171

第八节：事务管理与 AOP

8.1 事务管理

  • Spring 事务：@Transactional（底层 AOP，方法开事务、正常提交异常回滚）。
  • rollbackFor：默认只回滚运行时异常，@Transactional(rollbackFor = Exception.class) 全回滚。
  • propagation 传播行为：事务方法嵌套调用时怎么办——REQUIRED（默认，有就加入）、REQUIRES_NEW（挂起当前另起新事务，互不影响）、SUPPORTS 等。

视频：P172–P174

8.2 AOP 面向切面

  • 场景：统计方法耗时、记录操作日志这类横切逻辑散落各方法 → 抽成切面统一处理，业务无感。
  • 核心概念：连接点（可以被增强的方法）、切入点（实际增强的方法）、通知（增强逻辑）、切面（切入点 + 通知）。
  • 快速入门：依赖 spring-boot-starter-aop，切面类 @Aspect + @Component，@Around("execution(* com.xxx.service.impl.*.*(..))") 环绕通知里 proceed() 执行原方法。
  • 通知类型：@Around（最万能）@Before @After @AfterReturning @AfterThrowing；多个切面用 @Order 控制顺序；@Pointcut 抽取公共切入点表达式。
  • 切入点表达式：execution(修饰符 返回值 包名.类名.方法名(参数))，支持通配；@annotation(注解) 匹配带某注解的方法（自定义 @Log 注解标记要记日志的方法更优雅）。
  • 案例：记录操作日志——环绕通知收集操作时间/类/方法/参数/返回值/耗时 + ThreadLocal 取操作人，insert 进日志表。

视频：P175–P182

第九节：SpringBoot 原理与工程化

9.1 配置与 bean 管理

  • 配置优先级：命令行 > properties > yml > yaml（同名高优先级覆盖）。
  • bean 获取：applicationContext.getBean("name"或类型)；作用域：singleton（默认单例）/prototype（每次新建）；@Lazy 懒加载。
  • 第三方 bean：@Bean 方法注册，参数自动注入；多个配置类用 @Import 导入；@ConditionalOnProperty 按条件注册。

视频：P183–P186

9.2 起步依赖与自动配置原理

  • 起步依赖：spring-boot-starter-web 一条坐标传递引入 web 全套 jar，本质是 Maven 依赖传递。
  • 自动配置：@SpringBootApplication = @SpringBootConfiguration（配置类）+ @EnableAutoConfiguration（自动配置核心）+ @ComponentScan（包扫描）。
  • 原理主线：@EnableAutoConfiguration 通过 @Import(AutoConfigurationImportSelector) 读取所有 jar 里 META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports 文件，加载一堆自动配置类 → 每个配置类里用 @Conditional 系列条件（@ConditionalOnClass 有此类才配、@ConditionalOnMissingBean 用户没配才给默认）按需生效 —— 所以引入 starter 就能开箱即用。
  • 案例：自定义 starter：把某功能的自动配置类 + 条件装配 + AutoConfiguration.imports 文件打成 starter，别处引坐标即用。

视频：P187–P194

9.3 Maven 高级

  • 分模块设计：按功能拆模块（pojo / utils / 业务模块），复用与职责清晰。
  • 继承：子模块 <parent> 继承父工程，<dependencyManagement> 统一版本（子模块引依赖不写版本号），<properties> 统一定义版本变量。
  • 聚合：父工程 <modules> 聚合子模块，父打包子一起构建。
  • 私服：企业内网 Nexus（central 代理仓库 / releases 发布版 / snapshots 快照版），settings.xml 配镜像与认证，deploy 上私服。

视频：P195–P200
